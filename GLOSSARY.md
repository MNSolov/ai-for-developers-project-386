# Календарь звонков

Сервис записи на встречи по публичной ссылке: владелец календаря настраивает типы встреч, гость по ссылке выбирает свободный слот.

## Язык

**Владелец календаря**:
Пользователь, который создаёт типы встреч и принимает записи гостей.
_Избегать_: администратор, организатор

**Встреча**:
Событие, на которое гость занимает слот; проходит в отведённое время.
_Синоним_: Звонок — равноправное слово, без иерархии.
_Избегать_: аппоинтмент, митинг

**Гость**:
Человек, который открывает ссылку для записи и занимает слот, оставляя имя, почту и комментарий.
_Избегать_: клиент, посетитель

**Запись**:
Действие гостя по занятию слота и результат этого действия.
_Избегать_: бронирование, резервирование

**Звонок**:
То же, что Встреча; привычное слово в названиях — «Календарь звонков», «Вводный звонок».
_Синоним_: Встреча — равноправное слово, без иерархии.

**Календарь звонков**:
Название продукта.

**Слот**:
Свободный интервал времени в расписании владельца календаря, который гость может занять записью.
_Избегать_: окно

**Ссылка для записи**:
Публичная ссылка вида `/u/{owner}/{event}`, по которой гость выбирает слот.
_Избегать_: ссылка бронирования

**Страница записи**:
Экран, на который гость попадает по ссылке для записи, чтобы выбрать слот и оставить контакты.

**Тип встречи**:
Шаблон встречи, создаваемый владельцем календаря: название, длительность, интервалы доступности.
_Избегать_: услуга
